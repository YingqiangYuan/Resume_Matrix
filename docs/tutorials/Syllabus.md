# Syllabus

## 01-Learn-This-Project

Introduces the 1+N resume matrix methodology for the US job market: one master resume of Summary Variants and Bullet Sets, derive any company-targeted resume by deletion. Hands-on: read the 13-lesson curriculum, run the 10 first-class agent skills, walk absorb → quiz → elevate → interview → demo → publish. After completion, learners can elevate thin experience through the 6-stage qualify pipeline and publish a sanitized portfolio version.
