# Your Experiences

This folder stores your work history and projects. Each experience is documented separately so that AI tools can easily combine and reorder them for different resume versions.

## File Structure

Each file is named: `from-YYYY-MM-to-YYYY-MM-job-title.md`

Example: `from-2024-01-to-2024-06-software-engineer-intern.md`

See [from-YYYY-MM-to-YYYY-MM-work-experience-title-here.md](./from-YYYY-MM-to-YYYY-MM-work-experience-title-here.md) for the format template using STAR framework.

## What to Include in Each File

Write a description of what you did during that period. Include:

1. The company or organization name
2. Your role and responsibilities
3. Key projects you worked on
4. Skills you developed or used
5. Measurable impact or accomplishments

## How to Use These Files

When you build a resume (either the master resume or a role-specific one), you select the experiences relevant to that resume and rewrite the bullet points to match the role requirements.

This folder allows you to maintain a single source of truth for each experience, and then customize them as needed for different opportunities.
