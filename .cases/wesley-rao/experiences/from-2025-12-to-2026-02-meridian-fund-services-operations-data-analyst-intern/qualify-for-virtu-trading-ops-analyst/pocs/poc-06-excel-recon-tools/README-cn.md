# POC-06：用一个 Excel 对账工作簿复现手工基线来对照工具价值

> 严重度：🟠 Nice-to-have ｜ 估时：3 天 ｜ 对应 tutorial：[../../tutorials/06-excel-recon-tools-cn.md](../../tutorials/06-excel-recon-tools-cn.md)

## 一句话 pitch

用 Excel 手工核对一遍 POC-01 的一个账户并计时，来复现"手工对账"基线、给 case §8 的"手工 vs 工具"对照提供真实一端。

## 支撑的 case 决策

case §8"关于省时间的诚实处理"（手工计时基线）。

## 输入与 setup

- 拿 POC-01 的一个账户合成数据，用 Excel（VLOOKUP/数据透视）手工核对并计时。

## 期望产出物

1. 一个 Excel 对账工作簿。
2. 手工核对单账户的计时记录（n=3，诚实标注非严格研究）。
3. 一段 Bloomberg 是什么/做什么的认知短记。

## 成功标准（可自验）

- [ ] 能用 Excel 复现一次手工对账并讲清它慢在哪。
- [ ] 能诚实给出手工 vs 工具的量级对照（不夸大成"省 3 小时"）。
- [ ] 知道 Bloomberg 在这类岗位的定位（加分非必需）。
