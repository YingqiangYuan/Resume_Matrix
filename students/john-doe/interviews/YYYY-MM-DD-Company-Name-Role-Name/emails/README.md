# Email Records

This folder stores important emails related to this job opportunity. Save every significant communication here for your records.

## What to Save

1. Initial outreach or application confirmation
2. Phone screen invitations and follow-ups
3. Interview schedules and logistics
4. Feedback after interviews
5. Offer letters or rejection letters
6. Any other important communications from the company

## File Naming

Name each email file following the pattern: `YYYY-MM-DD-email-from-sender-name.md`

For example: `2024-06-15-email-from-sarah-recruiter.md`

## File Format

See [YYYY-MM-DD-email-from-sender-name.md](./YYYY-MM-DD-email-from-sender-name.md) for a template.

Each email file should include:

- The date you received the email
- The sender's name and title
- The full email content
- A quick summary of what this email means for your application

This creates a searchable backup copy of all communications with the company.
