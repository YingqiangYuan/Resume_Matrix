# Interview Records

This folder contains records of every job opportunity you apply for and interview with. Each opportunity gets its own subfolder.

## Inside Each Opportunity Folder

Each opportunity folder follows the structure shown in [YYYY-MM-DD-Company-Name-Role-Name/README.md](./YYYY-MM-DD-Company-Name-Role-Name/README.md)

Inside you will find:

- **README.md** — Overview of this specific opportunity and timeline
- **[company.md](./YYYY-MM-DD-Company-Name-Role-Name/company.md)** — Information about the company and key contacts
- **[job-description.md](./YYYY-MM-DD-Company-Name-Role-Name/job-description.md)** — The job description you applied for
- **[resume.md](./YYYY-MM-DD-Company-Name-Role-Name/resume.md)** — Resume version you submitted for this role
- **[emails/](./YYYY-MM-DD-Company-Name-Role-Name/emails/README.md)** — Copies of all communication with the company
- **[prep/](./YYYY-MM-DD-Company-Name-Role-Name/prep/README.md)** — Interview preparation materials

## How to Use

When you apply for a new role, create a new subfolder following the naming convention. Copy the job description and save the resume you are using. As you go through the interview process, update the README with your timeline and save important emails in the emails folder.

This creates a complete record of each opportunity and allows you to track your progress through the application and interview stages.
