## How This Differs From the Cedar Ridge Folder

The Cedar Ridge folder (`../from-2025-06-to-2025-09-CedarRidge-maternity-bi-agent/`) is the output of the elevate workflow (07 pattern). The whole Cedar Ridge internship actually happened. Elevation is about understanding and deepening the same work in retrospect, not running it again.

This Pulse folder is the output of the from-scratch workflow (08 pattern). The starting point was nothing relevant plus a JD. John designed a forward-looking project to use as take-home talking material and as a build spec once the offer landed, then actually got the Pulse Backend Intern offer and turned the project from "design" into "executed mature version."

The two folders are structurally symmetric. The only real difference is whether Stage 3 `mini-project-design` runs in elevate mode or from-scratch mode.
