# Master Resume

This is your baseline resume that captures your full work history, education, and accomplishments. Think of this as the complete version that contains everything.

In practice, you will not send this master resume to employers. Instead, you create role-specific versions (see resume-role-1.md, resume-role-2.md, resume-role-3.md) where you select and reorder experiences to best match each job family you're targeting.

## How to Build This

1. Start with your work experiences from the experiences/ folder
2. Add your education, certifications, and any other credentials
3. Include a summary of your key skills
4. Do not worry about length or focus at this stage. That comes in the role-specific versions.

See the resume-role-*.md files to understand how to create targeted versions of this resume.
